# GTA 7 — Vice City

Tarayıcıda çalışan, Three.js tabanlı açık dünya prototipi.

## Çalıştırma
GitHub Pages veya Render Static Site üzerinden yayınlanabilir. Build komutu gerekmez; yayın klasörü kök dizindir.

## Kontroller
- WASD: yürü / araç sür
- Shift: koş
- Space: zıpla
- E: araca bin / in
- 8: karakter değiştir
- 9: hikâye modu aç / kapat
- Sol tık veya F: yakın NPC'ye yumruk
- Fare: kamerayı döndür (oyun alanına tıkla)

## İlk prototipte
Miami esintili sahil, hastane başlangıcı, oteller, villalar, banka, market, palmiye ağaçları, banklar, NPC kalabalığı, trafik, araç kullanma, sağlık, para ve yıldızlı aranma göstergesi bulunur.

Bu, ilk oynanabilir temel sürümdür. Görevler, gerçek NPC rutinleri, polis yapay zekâsı, bina içleri, deniz araçları ve kayıt sistemi sonraki geliştirme aşamalarında eklenecektir.
